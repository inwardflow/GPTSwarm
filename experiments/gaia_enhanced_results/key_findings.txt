FOR AGENTGROUP PAPER:
The comparison is unfair on TWO dimensions:
1. Tool availability: 23% of questions require file processing that baselines cannot do
2. Model quality: gpt-5.1-codex-mini (custom API, possibly broken) vs gpt-4.1-mini (working)

To make a fair comparison for the paper, ALL methods should:
- Use the SAME model (or at least same-tier models)
- Have access to the SAME tool suite
- Only differ in their ARCHITECTURE (single-agent vs multi-agent, graph structure, etc.)
